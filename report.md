### Reflection
In this lab I modified the counter app and added some new features. I added a reset button which would set the counter to 0. I also created a variable to keep track of how many times the reset button is used. I added a condition as well that displays "You are on a roll" message only when the counter goes above the threshold of 12(which is the sum of last 3 numbers of roll no + 5) which taught how conditions can be used to display or hide widgets. I used a row so that the increment and reset buttons are displayed next to each other and a sizedBox to give them space. Then I used my own seedColor and added information to the screen.
